# A cultivation circuit with T gates

`chan_d5a19_uncorrected_T.stim`, for
`test/integration/test_determined_literature.py`, is a noiseless d=5 magic
state cultivation circuit from Chan, Strikis, Sun, Cai, arXiv:2609.17706,
[timchan0/cliffordea](https://github.com/timchan0/cliffordea)
`sim/stim_files/` at `27385c6` (MIT): an S proxy with S/S_DAG swapped for
T/T_DAG as in `circuit_text.swap_t_and_s_gates`, before the paper's d=5
correction (`sim/d5-correction.md`).
