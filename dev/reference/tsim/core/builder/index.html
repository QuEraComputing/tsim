    builder

    GraphBuilder: the ZX graph of a stim circuit and its bookkeeping.

    GraphBuilder owns the graph while a circuit is parsed: wire ends, measurement records, error bits, pending correlated errors, and detectors and observables. The gate library (tsim.core.instructions) builds on its methods and never adds vertices itself; build returns the finished open or closed graph.

    Qubit wires are quantum. Every wire vertex starts as a quantum boundary, and gates turn a wire's trailing boundary into a spider in place (see GraphBuilder.spider), so the spider stays quantum. Only measurements (merge_mirror_copies) and detector and observable annotations create classical vertices. NOTE: zxparam's Graph.add_vertex defaults to the classical domain, so wire vertices are only ever added here.

    ANNOTATION_ROW module-attribute 

    ANNOTATION_ROW = -2.0

    Row of the detector and observable spiders, above the helper wire.

    HELPER_LANE module-attribute 

    HELPER_LANE = -1

    Qubit index, and row, of the helper wire used by MPP, MPAD and heralded channels.

    MAX_CORRELATED_ERROR_BITS module-attribute 

    MAX_CORRELATED_ERROR_BITS = 20

    Most error bits of an E/ELSE_CORRELATED_ERROR chain's channel (2^20 outcomes).

    NOTE: channel simplification and the sampling tables visit every outcome of a channel, so compiling a 22-bit chain takes about a minute and 5 GB.

    Outputs module-attribute 

    Outputs = Literal['detectors', 'records', 'none']

    The classical outputs of a built graph (see GraphBuilder.build).

    def add_channel(self, probs: np.ndarray) -> int:
    """Record a noise channel and allocate its error bits.

    ``probs`` is the channel's distribution over its ``k`` error bits, so it
    has ``2^k`` entries. Returns the first bit; the channel owns bits
    ``first … first + k − 1``. Raises ``ValueError`` if the number of
    entries is not a power of two.
    """
    num_bits = channel_num_bits(probs)
    first = self._num_error_bits
    self._channel_probs.append(probs)
    self._num_error_bits += num_bits
    return first

    build 

    build(*, closed: bool, outputs: Outputs) -> Graph

    Return the circuit's graph with its wires closed or given ports.

    With closed=False, qubit q's wire start, if it is still a boundary, gets input port -(q + 1) and its end gets output port q. With closed=True, wire starts that are still boundaries become |0⟩ (a quantum X(0) spider) and wire ends are discarded. Helper lanes (negative indices, used by MPP, MPAD and heralded channels) are always discarded at the end.

    outputs picks the classical output boundaries, whose ports follow the qubit outputs (from 0 when closed):

    • "detectors": one per detector, then one per observable; the det[i] / obs[k] labels move to them.
    • "records": one per measurement record; the rec[i] labels move to them.
    • "none": no classical outputs.

    Detector and observable spiders are removed unless they are the outputs. In open graphs, measurement spiders that are not outputs keep their rec[i] / m[i] labels; closed graphs are meant to be reduced, so only their output boundaries carry labels, which survive reduction.

    An open graph's tensor is the circuit's channel together with the output bits; for bound error parameters, a closed graph's tensor is the joint distribution of its outputs. The builder is unchanged, so it can build again.

    def build(self, *, closed: bool, outputs: Outputs) -> Graph:
    """Return the circuit's graph with its wires closed or given ports.

    With ``closed=False``, qubit ``q``'s wire start, if it is still a
    boundary, gets input port ``-(q + 1)`` and its end gets output port
    ``q``. With ``closed=True``, wire starts that are still boundaries become
    ``|0⟩`` (a quantum X(0) spider) and wire ends are discarded. Helper lanes
    (negative indices, used by MPP, MPAD and heralded channels) are always
    discarded at the end.

    ``outputs`` picks the classical output boundaries, whose ports follow the
    qubit outputs (from 0 when closed):

    - ``"detectors"``: one per detector, then one per observable; the
      ``det[i]`` / ``obs[k]`` labels move to them.
    - ``"records"``: one per measurement record; the ``rec[i]`` labels move
      to them.
    - ``"none"``: no classical outputs.

    Detector and observable spiders are removed unless they are the outputs.
    In open graphs, measurement spiders that are not outputs keep their
    ``rec[i]`` / ``m[i]`` labels; closed graphs are meant to be reduced, so
    only their output boundaries carry labels, which survive reduction.

    An open graph's tensor is the circuit's channel together with the output
    bits; for bound error parameters, a closed graph's tensor is the joint
    distribution of its outputs. The builder is unchanged, so it can build
    again.
    """
    if outputs not in get_args(Outputs):
        raise ValueError(
            f"outputs must be one of {get_args(Outputs)}, got {outputs!r}"
        )
    self._check_finalized()
    g = self._graph.copy()
    self._align_wire_ends(g)
    if closed:
        for v in self._first_vertex.values():
            if g.vertex_type(v) == VertexType.BOUNDARY:
                g.plug_basis(v)
        for v in self._last_vertex.values():
            g.discard(v)
        first_port = 0
    else:
        for q, v in self._first_vertex.items():
            if q >= 0 and g.vertex_type(v) == VertexType.BOUNDARY:
                g.set_port(v, -(q + 1))
        for q, v in self._last_vertex.items():
            if q >= 0:
                g.set_port(v, q)
            else:
                g.discard(v)
        first_port = max((q for q in self._last_vertex if q >= 0), default=-1) + 1
    if outputs == "detectors":
        self._attach_detector_outputs(g, first_port)
    else:
        for v in [*self._detectors, *self.observables]:
            g.remove_vertex(v)
        if outputs == "records":
            self._attach_record_outputs(g, first_port)
    if closed:
        for v in [*self._records, *self._silent_records]:
            g.set_vertex_label(v, None)
    return g

    def correlated_error(
    self,
    qubits: list[int],
    types: list[Literal["X", "Y", "Z"]],
    p: float,
) -> None:
    """Add a correlated error term affecting multiple qubits with given Pauli types.

    The term is the next link of the pending chain. It flips one noise spider
    per Pauli component (X or Z on a qubit), reusing the chain's spider of
    that component while nothing else has acted on the wire since (see
    ``_chain_spider``). The spiders get their error bits in
    ``finalize_correlated_error``, which must run before the graph is built.
    Raises ``ValueError``, and changes nothing, if ``qubits`` and ``types``
    differ in length.
    """
    targets = list(zip(qubits, types, strict=True))
    term = len(self._correlated_error_probs)
    for qubit, type_ in targets:
        if type_ == "X" or type_ == "Y":
            self._chain_toggles[self._chain_spider(qubit, VertexType.X)] ^= {term}
        if type_ == "Z" or type_ == "Y":
            self._chain_toggles[self._chain_spider(qubit, VertexType.Z)] ^= {term}
    self._correlated_error_probs.append(p)

    def cz(
    self,
    control: int,
    target: int,
    classically_controlled: list[bool] | None = None,

    """Apply CZ; ``classically_controlled`` marks record targets (``rec[-k]``)."""
    if classically_controlled and classically_controlled[1]:
        if classically_controlled[0]:
            # NOTE: a CZ between two measurement records only phases classical
            # bits, so it does nothing (as in Stim).
            return
        # NOTE: CZ is symmetric, so the record becomes the control.
        classically_controlled = classically_controlled[::-1]
        control, target = target, control
    self._controlled(
        VertexType.Z, EdgeType.HADAMARD, control, target, classically_controlled
    )

    finalize_correlated_error() -> None

    Finalize the current correlated error channel.

    A chain of k links on c live noise spiders (those that some link flips) becomes a channel over min(c, k) error bits: one bit per spider if c < k, so that link j sets the bits of the spiders it flips, and one bit per link otherwise, so that a spider's phase is the parity of the links that flip it.     def finalize_correlated_error(self) -> None:
    """Finalize the current correlated error channel.

    A chain of ``k`` links on ``c`` live noise spiders (those that some link
    flips) becomes a channel over ``min(c, k)`` error bits: one bit per
    spider if ``c < k``, so that link ``j`` sets the bits of the spiders it
    flips, and one bit per link otherwise, so that a spider's phase is the
    parity of the links that flip it. Clears the pending chain, also when it
    raises ``ValueError`` because the channel would have more than
    ``MAX_CORRELATED_ERROR_BITS`` bits.
    """
    probabilities = self._correlated_error_probs
    if not probabilities:
        return
    spiders, toggles = self._chain_spiders, self._chain_toggles
    self._chain_spiders = []
    self._chain_toggles = []
    self._chain_runs = {}
    self._correlated_error_probs = []
    live = [i for i, links in enumerate(toggles) if links]
    k, c = len(probabilities), len(live)
    if min(c, k) > MAX_CORRELATED_ERROR_BITS:
        raise ValueError(
            f"an E/ELSE_CORRELATED_ERROR chain of {k} links on {c} Pauli "
            f"components needs 2^{min(c, k)} outcomes, more than the "
            f"2^{MAX_CORRELATED_ERROR_BITS} tsim supports; independent E "
            "instructions approximate it to first order in p"
        )
    # NOTE: a chain that flips no spider, such as E(p) X0 X0, has no channel.
    if 0 < c < k:
        masks = [0] * k
        for bit, i in enumerate(live):
            for term in toggles[i]:
                masks[term] |= 1 << bit
        first = self.add_channel(chain_error_probs(masks, probabilities, c))
        for bit, i in enumerate(live):
            self._graph.set_phase(spiders[i], error_phase(first + bit))
    elif c > 0:
        first = self.add_channel(correlated_error_probs(probabilities))
        for i in live:
            bits = frozenset(first + term for term in toggles[i])
            self._graph.set_phase(spiders[i], Phase(Fraction(0), bits))

    def measure(self, qubit: int, *, silent: bool = False) -> Vertex:
    """Measure a qubit in the Z basis and record it as ``rec[i]``.

    A silent measurement is not recorded; it is labelled ``m[i]``. Returns
    the measurement's classical spider.
    """
    self._ensure_lane(qubit)
    v1 = self._last_vertex[qubit]
    self._graph.set_vertex_type(v1, VertexType.Z)
    self._graph.merge_mirror_copies(v1)
    if not silent:
        self._graph.set_vertex_label(v1, f"rec[{len(self._records)}]")
        self._records.append(v1)
    else:
        self._graph.set_vertex_label(v1, f"m[{len(self._silent_records)}]")
        self._silent_records.append(v1)
    v2 = self._add_quantum_boundary(qubit)
    self._graph.add_edge(v1, v2)
    return v1

    def reset(self, qubit: int) -> None:
    """Reset a qubit to ``|0⟩``.

    If the qubit does not yet have a lane, create one in the reset state.
    Otherwise, silently measure the existing lane to trace out the previous
    state before reconnecting the qubit in the reset state.
    """
    if qubit not in self._last_vertex:
        self._graph.plug_basis(self._add_lane(qubit))
        return
    self.measure(qubit, silent=True)
    col = self._last_col(qubit)
    v1 = self._last_vertex[qubit]
    (v2,) = self._graph.neighbors(v1)
    self._graph.remove_edge(v1, v2)
    self._graph.plug_basis(v1)
    v3 = self._add_quantum_boundary(qubit, col + 1)
    self._graph.add_edge(v1, v3)

    def spider(

    def swap(self, qubit1: int, qubit2: int) -> None:
    """Swap two wires by exchanging their ends (and rows)."""
    self._ensure_lane(qubit1)
    self._ensure_lane(qubit2)

    v1 = self._last_vertex[qubit1]
    v2 = self._last_vertex[qubit2]
    self._last_vertex[qubit1] = v2
    self._last_vertex[qubit2] = v1

    # NOTE: both wire ends move to the later column first, so neither lands on
    # a position the other lane already uses.
    col = max(self._graph.col(v1), self._graph.col(v2))

    self._graph.set_col(v2, col)

    def tick(self) -> None:
    """Align all wire ends to the same column."""
    if len(self._last_vertex) == 0:
        return
    col = max(self._last_col(q) for q in self._last_vertex)
    for q in self._last_vertex:
        self._graph.set_col(self._last_vertex[q], col)
