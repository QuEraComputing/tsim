# Porting published circuits to Tsim

Papers about non-Clifford protocols often publish Stim circuits in which every T gate is
replaced by a Clifford stand-in, because Stim cannot simulate T. Tsim can, so the same circuits
can be rerun with real T gates. This skill covers getting the circuits, converting them, checking
the conversion, and deciding what is feasible. It builds on the `tsim` skill (active width,
sampling) and hands off to `tsim-qec-study` for the actual statistics.

## 1. Find the published circuits

Use the authors' files whenever they exist; regenerating circuits from the paper's description
introduces differences that are hard to find later.

- **arXiv source:** `https://arxiv.org/e-print/<arxiv-id>` downloads the source bundle (usually
  a gzipped tar). Circuits are sometimes attached as `.stim` files, and the `.tex` names data and
  code links that the PDF hides. Treat downloaded archives as untrusted: unpack into an empty
  directory and only read the files.
- **Code and data links:** GitHub, Zenodo and figshare links in the paper, its data
  availability statement, and the authors' GitHub profiles. Circuits are also embedded in
  notebooks or generated by scripts in these repositories.
- **Ask the user** whether they have circuits from the authors before rebuilding anything.

Record where each circuit came from (URL and commit or version) next to the circuit file.

## 2. Load and convert stand-in gates

```python
import tsim

c = tsim.Circuit(
    """
    RX 0
    S 0
    DEPOLARIZE1(0.001) 0
    S_DAG 0
    MX 0
    OBSERVABLE_INCLUDE(0) rec[-1]
    """
)
```

Use `tsim.Circuit.from_file(path)` for files; `tsim.Circuit(...)` also accepts a `stim.Circuit`.
Tsim accepts every Stim instruction.

Read the paper's methods section to find which gates stand in for T. Common conventions:

- `S` and `S_DAG` in place of `T` and `T_DAG` (the most common; the protocol's checks then see
  an S state, which is also a stabilizer state);
- tagged instructions, such as Tsim's own `S[T]` and `S_DAG[T]`, which Tsim already reads as
  `T` and `T_DAG`;
- a comment, coordinate or `QUBIT_COORDS` marker identifying the magic qubits.

Replace only the stand-ins: a circuit can also contain ordinary `S` gates that must stay. When
the stand-ins are not marked, find them from the paper (for example, the gates on the injection
qubit and in the check rounds) and confirm the choice with the user.

When every `S` and `S_DAG` is a stand-in, a line-anchored substitution converts them all:

```python
import re

real_text = re.sub(r"^(\s*)S(_DAG)?(?=[\s\[])", r"\1T\2", str(c), flags=re.MULTILINE)
real = tsim.Circuit(real_text)
assert real.tcount() == 2
```

When only some are stand-ins, change those lines individually (for example, only the `S`
lines that target the injection qubit), and compare `real.tcount()` with the number of T gates
the paper states.

## 3. Validate the conversion

Run these checks before trusting any number from the converted circuit:

1. **Stand-in matches Stim.** Sample the original stand-in circuit in Tsim (with
   `use_detector_reference_sample=True` and `use_observable_reference_sample=True`) and in Stim.
   Detector and observable rates must agree within error bars. If the paper reports numbers for
   the stand-in circuit, reproduce one of them.
2. **Noiseless real circuit.** In `real.without_noise()`, every detector used for postselection
   or decoding must be 0 on every shot, and the output should be the ideal state (for example,
   infidelity 0 with the `tsim-qec-study` fidelity measurement). A detector that fires without
   noise usually means a stand-in was missed or a non-stand-in `S` was converted.
3. **Observables of the stand-in.** Sample the noiseless stand-in and check whether its
   observables are deterministic. Often they are not: a final check written as `S; MPP Y;
   S_DAG` measures the T state's stabilizer once S becomes T, but measures X on the stand-in's
   S state, which is random. Such a stand-in gives only acceptance rates, not logical error
   rates; say so instead of reporting a meaningless error rate. To compare error rates, build a
   stand-in variant whose final check matches the S state (for example, drop the `S`/`S_DAG`
   around `MPP Y`), label it as your modification, and verify it is deterministic without noise.
   Conversely, check that the real-T circuit's observables are deterministic without noise; if
   the output is a magic state measured directly, use the fidelity measurement in
   `tsim-qec-study` instead.

## 4. Measure the active width (k_max)

Compile without sampling and read the active width, which sets the cost per shot (see the
`tsim` skill for the scale). This is cheap even for large circuits.

```python
sampler = real.compile_detector_sampler()
print(real.num_qubits, real.tcount(), real.num_detectors, sampler.active_width)
```

When surveying several circuits or sizes, report one row per circuit:

| Circuit (source) | Qubits | T count | Detectors | Active width | Shots/s (cores) |
|---|---|---|---|---|---|

Measure shots per second only for circuits whose width makes it quick, with postselection on if
the protocol postselects, and state the number of threads. If a family of circuits is surveyed
by size (distance, rounds), report how the width grows; that is often the main result.

## 5. Plan the study

- Width small enough: run the paper's figure with real T gates using `tsim-qec-study`, and plot
  the stand-in and real results together; the difference is usually the point.
- Width too large: say so with the measured width and an estimate of time per shot, and suggest
  the largest instance that is feasible.
- Note anything Tsim cannot express. Simulator-specific instructions from other tools (for
  example expectation-value instructions) need a Tsim equivalent such as the fidelity
  measurement in `tsim-qec-study`.

If a published circuit fails to parse or compile in Tsim although Stim accepts it, reduce it to
a small reproducer and report it as described in the `tsim` skill.
