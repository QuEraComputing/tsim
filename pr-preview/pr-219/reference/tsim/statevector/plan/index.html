    plan

    Fixed-width sampling plans.

    plan walks scheduled Pauli ops with a Clifford frame F: a stim.Tableau that maps Paulis of the |0…0⟩ frame to virtual coordinates. Virtual coordinates 0 … W-1 are the axes of a dense array of 2^W amplitudes, each active or free (in |0⟩); coordinates W … n-1 stay dormant (in |0⟩). Each op becomes at most one action, and every sign an AffineRow over the symbols: the component f-bits, then the branch bits of random measurements. A random measurement keeps the reference state on its b = 0 branch; its b = 1 branch differs by a correction Pauli, which flips the sign of every later op it anticommutes with. Each output is an AffineRow too: the measurement's sign, XOR its branch bit if it is random.

    def evaluate(self, symbols: Sequence[int]) -> int:
    """Return the parity's value for the given symbol bits."""
    return int(self.constant) ^ (sum(symbols[t] for t in self.terms) & 1)

    def plan(ops: PauliOps, schedule: Schedule) -> Plan:
    """Return the fixed-width plan of ``ops`` in schedule order.

    Raises:
        RuntimeError: If the ops need more than ``schedule.width`` active axes.

    """
    planner = _Planner(ops.take(schedule.order), schedule.width)
    for j in range(ops.num_ops):
        planner.step(j)
    return Plan(
        width=schedule.width,
        num_f=ops.num_f,
        actions=tuple(planner.actions),
        outputs=tuple(planner.outputs[slot] for slot in range(ops.num_outputs)),
    )
