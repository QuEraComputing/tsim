title: "Installation"
description: "Install Tsim with uv or pip, with optional GPU support."
---

Tsim requires Python 3.11 or later.

## Using uv (recommended)

We recommend using [`uv`](https://docs.astral.sh/uv/) for dependency management.

```bash
uv add bloqade-tsim
```

For GPU acceleration with CUDA:

```bash
# For CUDA 13
uv add "bloqade-tsim[cuda13]"

# For CUDA 12
uv add "bloqade-tsim[cuda12]"
```

## Using pip

```bash
pip install bloqade-tsim
```

For GPU acceleration with CUDA:

```bash
pip install "bloqade-tsim[cuda13]"
```

## Apple GPUs

On an Apple-silicon Mac, the default strategy (`"active_statevector"`) can sample on the GPU
through Metal. It needs PyObjC's Metal bindings, which the `metal` extra installs:

```bash
uv add "bloqade-tsim[metal]"    # or: pip install "bloqade-tsim[metal]"
```

With it installed, the samplers use the GPU whenever every component of the circuit has at
most 11 active qubits; otherwise they sample on the CPU, with a warning. The GPU computes in
float32, so a sample follows the CPU's distribution to within float32 rounding, and a seed's
samples differ from the CPU's (and depend on `batch_size`). Postselection runs on the GPU, so
heavily postselected circuits gain the most. Set `TSIM_DEVICE=cpu` to keep the samplers on the
CPU, for example to reproduce samples from another machine.

## Agent skill

Tsim ships an agent skill that teaches coding agents (Claude Code, Codex, Cursor and others)
how to judge whether a circuit is feasible, sample and postselect it, run logical error rate
studies, and port published Stim circuits. Install it with [Ion](https://github.com/roger-luo/ion):

```bash
ion add QuEraComputing/tsim/skills/simulating-circuits-with-tsim
```

or with `npx skills`:

```bash
npx skills add QuEraComputing/tsim --skill simulating-circuits-with-tsim
```

The skill is also served by this site at `/.well-known/skills/`.

## Docs MCP server

This site runs an MCP server at `https://bloqade.quera.com/tsim/mcp` that lets agents search
and read these docs. Add it to Claude Code with:

```bash
claude mcp add --transport http tsim https://bloqade.quera.com/tsim/mcp
```

For Cursor and VS Code, use the page menu at the top of any page.

## Development setup

If you're contributing to Tsim, clone the repository and install development dependencies:

```bash
git clone https://github.com/QuEraComputing/tsim.git
cd tsim
uv sync
```

Install pre-commit hooks to run linting checks automatically:

```bash
pre-commit install
```

This will run formatters and linters (black, isort, ruff, pyright) before each commit.
