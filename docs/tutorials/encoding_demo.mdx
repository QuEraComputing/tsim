This tutorial showcases the basic functionality of **Tsim**.

Tsim is a circuit sampler for Clifford+T circuits, based on stabilizer rank decomposition and ZX-calculus techniques. It closely follows the API of Stim and directly uses Stim's circuit format.

In contrast to Stim, Tsim supports `T` and `T_DAG` instructions.

The following circuit demonstrates this by preparing and measuring the state
$$
H\,T\,|+\rangle
= e^{i\pi/8}\Big[\cos\!\left(\tfrac{\pi}{8}\right)\,|0\rangle
\;-\; i\,\sin\!\left(\tfrac{\pi}{8}\right)\,|1\rangle\Big].
$$


```python
c = Circuit("""
    RX 0
    T 0
    H 0
    M 0
    """)
c.diagram("timeline-svg", height=150)
```

To sample from this circuit, we first compile it into a sampler:


```python
sampler = c.compile_sampler()
```

We can now sample bitstrings from the measurement instructions:


```python
sampler.sample(shots=10)
```




```text title="Output"
array([[False],
       [False],
       [False],
       [False],
       [False],
       [False],
       [False],
       [False],
       [False],
       [False]])
```




Let's run a large number of shots to estimate the probability of measuring `1`.


```python
samples = sampler.sample(shots=10_000_000, batch_size=1_000_000)
int(np.count_nonzero(samples)) / len(samples)
```




```text title="Output"
0.1464343
```




As expected, the probability is close to $\sin(\pi/8)^2 \approx 0.1464$.

## Detectors and Observables

Next, we consider a more complex example: an encoding circuit for the [[7,1,3]] Steane code. This circuit prepares the logical state

$$\frac{1}{2}\Big[(1 + e^{i\pi/4})|\bar{0}\rangle + (1 - e^{i\pi/4})|\bar{1}\rangle\Big]$$


```python
c = Circuit("""
    RX 6
    T 6
    H 6
    R 0 1 2 3 4 5
    SQRT_Y_DAG 0 1 2 3 4 5
    CZ 1 2 3 4 5 6
    SQRT_Y 6
    CZ 0 3 2 5 4 6
    SQRT_Y 2 3 4 5 6
    CZ 0 1 2 3 4 5
    SQRT_Y 1 2 4
    X 3
    TICK
    M 0 1 2 3 4 5 6
    DETECTOR rec[-7] rec[-6] rec[-5] rec[-4]
    DETECTOR rec[-6] rec[-5] rec[-3] rec[-2]
    DETECTOR rec[-5] rec[-4] rec[-3] rec[-1]
    OBSERVABLE_INCLUDE(0) rec[-7] rec[-6] rec[-2]
    """)
```

Tsim supports multiple visualization methods. The default makes use of `stim`'s "timeline-svg" visualization function:


```python
c.diagram(height=350)
```

## Adding Noise

A core capability of Tsim is its support for Pauli noise channels.

Let's look at a simple example. We'll insert a depolarizing channel `DEPOLARIZE1(0.01)` before the final stabilizer measurements.


```python
def make_circuit(p):
    return Circuit(f"""
        RX 6
        T 6
        H 6
        R 0 1 2 3 4 5
        TICK
        SQRT_Y_DAG 0 1 2 3 4 5
        DEPOLARIZE1({p}) 0 1
        TICK
        CZ 1 2 3 4 5 6
        DEPOLARIZE2({p}) 1 2
        TICK
        SQRT_Y 6
        DEPOLARIZE1({p}) 6
        TICK
        CZ 0 3 2 5 4 6
        TICK
        SQRT_Y 2 3 4 5 6
        DEPOLARIZE1({p}) 2 4 6
        TICK
        CZ 0 1 2 3 4 5
        TICK
        DEPOLARIZE1({p}) 0 1 2 3 4 5 6
        SQRT_Y 1 2 4
        X 3
        TICK
        M 0 1 2 3 4 5 6
        DETECTOR rec[-7] rec[-6] rec[-5] rec[-4]
        DETECTOR rec[-6] rec[-5] rec[-3] rec[-2]
        DETECTOR rec[-5] rec[-4] rec[-3] rec[-1]
        OBSERVABLE_INCLUDE(0) rec[-7] rec[-6] rec[-2]
        """)


c = make_circuit(0.01)
```

            if (n.row &lt; minRow) minRow = n.row;
            if (n.row &gt; maxRow) maxRow = n.row;

        // no longer reserve vertical space for it inside the SVG itself.

        // scroll horizontally instead of being clipped by the SVG viewport.
        if (showScalar) {

            scalarDiv.textContent = &quot;scalar: &quot; + graphJson.scalar;
            scalarDiv.style.fontFamily = TEXT_STYLE.fontFamily;
            scalarDiv.style.fontSize = TEXT_STYLE.scalar.fontSize;

        // so it stays unambiguous which vertices an edge actually connects.

        // Spatial index over nodes: each edge queries candidates within its
        // inflated bounding box, cutting obstruction scans from O(N) to O(log N)
        // on average. Kept in sync with node moves by the drag handler.
        const nodeTree = d3.quadtree()
            .x(function (n) { return n.x; })
            .y(function (n) { return n.y; })
            .addAll(nodes);

        // Always emit a quadratic-bezier path (with midpoint control when
        // straight) so d3's default string interpolator can smoothly animate
        // straight ↔ curved transitions during drag.
        function edgePath(edge) {
            const sx = edge.source.x, sy = edge.source.y;
            const tx = edge.target.x, ty = edge.target.y;
            const dx = tx - sx, dy = ty - sy;
            const midX = (sx + tx) / 2, midY = (sy + ty) / 2;
            const L2 = dx * dx + dy * dy;
            if (L2 &lt; EDGE_STYLE.zeroLengthEpsilon) {
                return &quot;M &quot; + sx + &quot;,&quot; + sy + &quot; Q &quot; + midX + &quot;,&quot; + midY + &quot; &quot; + tx + &quot;,&quot; + ty;
            }
            const L = Math.sqrt(L2);

            // Segment AABB inflated by obstructRadius — any obstructing node
            // must fall inside this box.
            const bxMin = Math.min(sx, tx) - obstructRadius;
            const bxMax = Math.max(sx, tx) + obstructRadius;
            const byMin = Math.min(sy, ty) - obstructRadius;
            const byMax = Math.max(sy, ty) + obstructRadius;

            let sumSigned = 0;
            let count = 0;
            nodeTree.visit(function (qnode, qx0, qy0, qx1, qy1) {
                if (qx0 &gt; bxMax || qx1 &lt; bxMin || qy0 &gt; byMax || qy1 &lt; byMin) {
                    return true;  // quadrant can't contain a candidate — prune
                }
                if (!qnode.length) {
                    // Leaf: walk the coincident-points linked list.
                    let leaf = qnode;
                    do {
                        const n = leaf.data;
                        if (n !== edge.source &amp;&amp; n !== edge.target) {
                            const along = ((n.x - sx) * dx + (n.y - sy) * dy) / L2;
                            if (
                                along &gt;= EDGE_STYLE.obstructionRange.min &amp;&amp;
                                along &lt;= EDGE_STYLE.obstructionRange.max
                            ) {
                                const perp = (dx * (n.y - sy) - dy * (n.x - sx)) / L;
                                if (Math.abs(perp) &lt; obstructRadius) {
                                    sumSigned += perp;
                                    count++;
                                }
                            }
                        }
                        leaf = leaf.next;
                    } while (leaf);
                }
                return false;
            });

            let cx = midX, cy = midY;
            if (count &gt; 0) {
                // Offset the control point perpendicular to the segment,
                // away from the side with the heaviest obstruction.
                const sign = sumSigned &gt; 0 ? -1 : 1;
                const offsetMag = obstructRadius + EDGE_STYLE.curveOffset;
                cx = midX + (-dy / L) * sign * offsetMag;
                cy = midY + (dx / L) * sign * offsetMag;
            }
            return &quot;M &quot; + sx + &quot;,&quot; + sy + &quot; Q &quot; + cx + &quot;,&quot; + cy + &quot; &quot; + tx + &quot;,&quot; + ty;
        }

            .attr(&quot;stroke&quot;, COLORS.outline)
            .attr(&quot;stroke-width&quot;, function (d) {
                return isQuantumDomain(d.domain)
                    ? NODE_STYLE.strokeWidth.quantum
                    : NODE_STYLE.strokeWidth.classical;
            });

        // edge). Non-boundary nodes with a phase will stack the phase above
        // the label; see the phase block below.
        node.filter(function (d) { return d.label; })
            .append(&quot;text&quot;)
            .attr(&quot;y&quot;, function (d) {

            .attr(&quot;font-size&quot;, TEXT_STYLE.label.fontSize)
            .attr(&quot;font-family&quot;, TEXT_STYLE.fontFamily)
            .attr(&quot;font-weight&quot;, TEXT_STYLE.label.fontWeight)
            .attr(&quot;fill&quot;, COLORS.labelText)
            .attr(&quot;style&quot;, TEXT_STYLE.interaction);

                .attr(&quot;font-size&quot;, TEXT_STYLE.index.fontSize)
                .attr(&quot;font-family&quot;, TEXT_STYLE.fontFamily)
                .attr(&quot;fill&quot;, COLORS.indexText)
                .attr(&quot;style&quot;, TEXT_STYLE.interaction);
        }

        // Drag: update node position and re-render edges. d3 v7 passes
        // (event, datum) to the callback (unlike v5's d3.event).
        //
        // Incident edges are recomputed every tick — their endpoints must
        // track the cursor. Non-incident edges only change because the
        // dragged node may newly obstruct / un-obstruct them, so we batch
        // their refresh through requestAnimationFrame, bounding the cost to

        let nonIncidentPending = false;
        let dragTarget = null;

            .on(&quot;start&quot;, function (event, d) {
                d3.select(this).attr(&quot;style&quot;, INTERACTION_STYLE.activeCursor);
                dragTarget = d;
            })
            .on(&quot;drag&quot;, function (event, d) {

                nodeTree.remove(d);
                d.x += event.dx;
                d.y += event.dy;
                nodeTree.add(d);
                d3.select(this).attr(&quot;transform&quot;, &quot;translate(&quot; + d.x + &quot;,&quot; + d.y + &quot;)&quot;);

                link.filter(function (l) { return l.source === d || l.target === d; })
                    .transition(&quot;edge-follow&quot;)
                    .duration(EDGE_STYLE.followTransitionMs)
                    .ease(d3.easeCubicOut)
                    .attr(&quot;d&quot;, edgePath);

                if (!nonIncidentPending) {
                    nonIncidentPending = true;
                    requestAnimationFrame(function () {
                        nonIncidentPending = false;
                        const target = dragTarget;
                        if (!target) return;
                        link.filter(function (l) { return l.source !== target &amp;&amp; l.target !== target; })
                            .transition(&quot;edge-follow&quot;)
                            .duration(EDGE_STYLE.followTransitionMs)
                            .ease(d3.easeCubicOut)
                            .attr(&quot;d&quot;, edgePath);
                    });
                }
            })
            .on(&quot;end&quot;, function () {
                d3.select(this).attr(&quot;style&quot;, INTERACTION_STYLE.idleCursor);
                dragTarget = null;
            });

        node.call(drag);

        return svg.node();
    }

    // CommonJS-style export for bundlers/tests.

## Error detection

One simple error correction strategy is **post-selection**: we discard any shots where a detector fired (indicating an error occurred). This effectively projects us back to the code space, but reduces the success rate (yield).


```python
perfect_stabilizers = np.all(det_samples == 0, axis=1)
post_selected_obs = obs_samples[perfect_stabilizers]
int(np.count_nonzero(post_selected_obs)) / len(post_selected_obs)
```




```text title="Output"
0.1430745814307458
```




## Error correction

To actively correct errors, we need a **decoder**. A decoder takes the detector syndrome and predicts whether the observable should be flipped.

In this example, we will use the [tesseract](https://github.com/quantumlib/tesseract-decoder) decoder.

After correction, we see that the the probability of getting a logical $|\bar{1}\rangle$ is close to the ideal value.


```python
c.detector_error_model()
```




```text title="Output"
stim.DetectorErrorModel('''
    error(0.0132444) D0 D1 D2
    error(0.0184365) D0 D1 L0
    error(0.00666667) D0 D2
    error(0.00666667) D0 L0
    error(0.0132444) D1 D2
    error(0.00666667) D1 L0
    error(0.0197345) D2
''')
```





```python
config = tesseract.TesseractConfig(dem=c.detector_error_model())
decoder = config.compile_decoder()


obs_corrected = np.zeros_like(obs_samples)
for i, det_sample in enumerate(det_samples):
    flip_obs = decoder.decode(det_sample)
    obs_corrected[i] = np.logical_xor(obs_samples[i], flip_obs[0])

print("Raw obs.: ", int(np.count_nonzero(obs_samples)) / len(obs_samples))
print("Corrected:", int(np.count_nonzero(obs_corrected)) / len(obs_corrected))
```

```text title="Output"
Raw obs.:  0.1663
Corrected: 0.1458
```



## Monte Carlo Simulation with sinter

Tsim is compatible with sinter, a tool for performing large Monte Carlo simulations. We can use sinter to sample and decode over a range of physical error rates.


```python
tesseract_dec = TesseractSinterDecoder()
no_dec = NoDecoder()

tasks = [
    sinter.Task(
        circuit=make_circuit(noise),  # type: ignore[arg-type]
        json_metadata={"p": noise},
    )
    for noise in np.logspace(-3.3, -0.2, 6)
]

collected_stats = sinter.collect(
    num_workers=1,
    tasks=tasks,
    decoders=["tesseract", "no decoding"],
    max_shots=1024 * 64,
    max_errors=1024 * 64,
    custom_decoders={"tesseract": tesseract_dec, "no decoding": NoDecoder()},
    start_batch_size=1024 * 64,
    max_batch_size=1024 * 64,
)
```

```text title="Output"
An NVIDIA GPU may be present on this machine, but a CUDA-enabled jaxlib is not installed. Falling back to cpu.
```



sinter provides a number of convenient plotting tools. Here, we use them to plot the observable flip rate as a function of the physical error rate. We observe that the decoded probability approaches the expected value of $\sin(\pi/8)^2$ much faster.


```python
fig, ax = plt.subplots(1, 1)
```
