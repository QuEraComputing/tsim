## class `CompiledComponent`

```python
CompiledComponent()
```

A single compiled connected component of a circuit.

Each component is independent and can be sampled separately. The results
are then combined according to output_indices.


## class `CompiledProgram`

```python
CompiledProgram(components: tuple[CompiledComponent | StatevectorComponent, ...], direct_f_indices: np.ndarray, direct_flips: np.ndarray, output_order: np.ndarray, output_reindex: np.ndarray | None, num_outputs: int, num_detectors: int)
```

A fully compiled circuit program ready for sampling.

This is the result of compiling a SamplingGraph and contains everything
needed to sample from the circuit.


## class `CompiledScalarGraphs`

```python
CompiledScalarGraphs()
```

JAX-compatible compiled representation of a list of scalar ZX graphs.

The scalar for each graph is a product of four exact term families and the
floating-point ``FloatTerms`` family, multiplied by a per-graph
``ScalarPrefactor`` (an exact Dyadic factor with its ``2^power2``, and an
approximate complex factor for angles that are not multiples of π/4). All
arrays are static-shaped so the whole struct can be traced under ``jax.jit``.


## class `ParamLayout`

```python
ParamLayout(num_errors: int)
```

Integer IDs for Tsim's parameters, fixed by the number of error bits.

Error bit ``j`` has ID ``j``, so error IDs are error indices. Above them,
error-basis and output bits are interleaved: basis bit ``j`` has ID
``num_errors + 2j`` and output bit ``i`` has ID ``num_errors + 2i + 1``. An
ID therefore means the same thing at every pipeline stage, whatever the
numbers of basis and output bits; names exist only for drawing.

```python

```

Return the ID of error-basis bit ``j``.


### `basis_index`

```python
basis_index(param: int) -> int
```

Return ``j`` for the error-basis bit whose ID is ``param``.


### `error`

```python
error(j: int) -> int
```

Return the ID of error bit ``j``.


### `kind`

```python
kind(param: int) -> tuple[ParamKind, int]
```

Return the kind of the bit with ID ``param`` and its index.


### `name`


### `names`

## class `SamplingGraph`

```python
SamplingGraph(graph: Graph, error_transform: np.ndarray, channel_probs: list[np.ndarray], num_outputs: int, num_detectors: int, layout: ParamLayout)
```

Result of the graph preparation phase for sampling.

Contains all data structures needed for sampling. This represents a circuit
that has been:
1. Parsed from stim format into a quantum/classical ZX graph (quantum
   wires, classical measurement records)
2. Closed into a sampling graph with classical output boundaries
3. Reduced via zxparam's full_reduce
4. Had its error basis transformed (Gaussian elimination: e → f)


## class `StatevectorComponent`

```python
StatevectorComponent(output_indices: tuple[int, ...], width: int, tape: Tape)
```

A component compiled for ``strategy="active_statevector"``.

Its lanes hold ``2^width`` complex128 amplitudes.


## `classify_direct`

```python
classify_direct(component: Graph, layout: ParamLayout) -> tuple[int, bool] | None
```

Return ``(basis index, flip)`` for a direct output; index -1 means constant.

That is the case when the component is a classical output boundary joined by
a Hadamard edge to a classical Z spider whose phase is 0 or π plus at most
one error-basis parameter.


## `compile_program`

```python
compile_program(prepared: SamplingGraph, mode: DecompositionMode, strategy: SamplingStrategy) -> CompiledProgram
```

Compile a prepared graph into an executable sampling program.

The graph is split into connected components. A component whose single
output equals one error-basis bit or a constant takes the direct path. With
``strategy="active_statevector"`` every other component becomes an action tape for
the statevector executor. Otherwise its outputs are plugged (all prefixes
in ``sequential`` mode, none and all in ``joint`` mode), each plugged graph
is decomposed into stabilizer terms, and the terms are compiled into JAX
arrays.

**Parameters:**

- `prepared` (`SamplingGraph`) — The prepared graph from ``prepare_graph``.
- `mode` (`DecompositionMode`) — ``"sequential"`` for sampling, ``"joint"`` for probabilities.
- `strategy` (`SamplingStrategy`) — ``"active_statevector"``, or a stabilizer-rank decomposition strategy.

**Returns:**

- `CompiledProgram` — A CompiledProgram ready for sampling.

**Raises:**

- `ValueError` — If ``strategy="active_statevector"`` is combined with ``mode="joint"``.


## `compile_scalars`

```python
compile_scalars(scalars: list[Scalar], param_ids: list[int]) -> CompiledScalarGraphs
```

Compile exact scalars, one per stabilizer term, into JAX arrays.

Column ``k`` of the parameter values the result is evaluated on holds the bit
of parameter ``param_ids[k]``. Each scalar is ``Scalar.simplified`` first,
and zero scalars are dropped. Angles that are multiples of π/4 stay exact;
other angles go into each term's float factor (terms without parameters) or
into the float term family.

**Raises:**

- `KeyError` — A term uses a parameter that is not in ``param_ids``.
- `OverflowError` — A Dyadic coefficient does not fit in int32.


## `compile_statevector_component`

```python
compile_statevector_component(component: Graph, output_indices: Sequence[int], layout: ParamLayout) -> StatevectorComponent
```

Compile one non-direct component for ``strategy="active_statevector"``.

**Parameters:**

- `component` (`Graph`) — A connected component of the prepared sampling graph.
- `output_indices` (`Sequence[int]`) — Global output index of each of the component's outputs.
- `layout` (`ParamLayout`) — The prepared graph's parameter layout.
