## class `ParamLayout`

```python
ParamLayout(num_errors: int)
```

Integer IDs for Tsim's parameters, fixed by the number of error bits.

Error bit ``j`` has ID ``j``, so error IDs are error indices. Above them,
error-basis and output bits are interleaved: basis bit ``j`` has ID
``num_errors + 2j`` and output bit ``i`` has ID ``num_errors + 2i + 1``. An
ID therefore means the same thing at every pipeline stage, whatever the
numbers of basis and output bits; names exist only for drawing.


### `basis`

```python
basis(j: int) -> int
```

Return the ID of error-basis bit ``j``.


### `basis_index`

```python
basis_index(param: int) -> int
```

Return ``j`` for the error-basis bit whose ID is ``param``.


### `error`

```python
error(j: int) -> int
```

Return the ID of error bit ``j``.


### `kind`

```python
kind(param: int) -> tuple[ParamKind, int]
```

Return the kind of the bit with ID ``param`` and its index.


### `name`

```python
name(param: int) -> str
```

Return the display name ``e\{j\}``, ``f\{j\}`` or ``m\{i\}`` of ``param``.


### `names`

```python
names(params: Iterable[int]) -> dict[int, str]
```

Return the display names of ``params``, by ID.


### `output`

```python
output(i: int) -> int
```

Return the ID of output bit ``i``.


## `draw_zx`

```python
draw_zx(g: Graph, num_errors: int, kwargs: dict[str, Any], layout: Layout = 'auto') -> Any
```

Draw ``g`` with zxparam's D3 viewer, naming its parameters.

**Parameters:**

- `g` (`Graph`) — The graph to draw; it is not changed.
- `num_errors` (`int`) — The circuit's number of error bits (see ``ParamLayout``).
- `kwargs` (`dict[str, Any]`) — Options for ``zxparam.draw`` (``labels``, ``param_names``, ``layout``, ``scale``), plus ``scale_horizontally``, a factor on the horizontal spacing. ``param_names`` entries override the generated names, and ``layout`` overrides the ``layout`` argument. Not modified.
- `layout` (`Layout`) — zxparam's drawing layout unless ``kwargs`` sets one.

**Returns:**

- `Any` — zxparam's D3 drawing object.

## `parse_parametric_tag_text`

```python
parse_parametric_tag_text(tag: str) -> tuple[str, dict[str, Fraction]] | None
```

Parse a parametric gate tag such as ``R_Z(theta=0.3*pi)`` or ``R_Z(0.3)``.

Angles are in units of pi. They are given either all by keyword with an
explicit ``*pi`` suffix, or all by position (``U3`` takes theta, phi, lambda
in that order, as in the shorthand).

**Parameters:**

- `tag` (`str`) — The stim instruction tag.

**Returns:**

- `tuple[str, dict[str, Fraction]] | None` — Tuple of (gate_name, params_dict), or ``None`` when the tag does not have
- `tuple[str, dict[str, Fraction]] | None` — the ``name(...)`` shape.

**Raises:**

- `ValueError` — When the tag has the ``name(...)`` shape but is malformed: an unknown gate name, an unparsable angle, or the wrong parameters.


## `placeholders_to_t`

```python
placeholders_to_t(svg_string: str, placeholder_id_to_labels: dict[float, GateLabel]) -> str
```

Replace I_ERROR placeholder gates in an SVG diagram with actual gate names.

Supported gates are T, T†, R_Z, R_X, R_Y, U_3.

**Parameters:**

- `svg_string` (`str`) — The SVG string from stim's diagram() method containing I_ERROR placeholder gates whose p-value are used as identifiers.
- `placeholder_id_to_labels` (`dict[float, GateLabel]`) — Mapping from identifier (float), i.e. the p values of I_ERROR gates, to GateLabel.

**Returns:**

- `str` — Modified SVG string with I_ERROR gates replaced by the actual gate names.

## `wrap_svg`

```python
wrap_svg(svg: str, width: float | None = None, height: float | None = None) -> str
```

Wrap an SVG string in a container div.

**Parameters:**

- `svg` (`str`) — Raw SVG markup.
- `width` (`float | None`) — Width of the container in pixels.
- `height` (`float | None`) — Height of the container in pixels (unused, kept for API symmetry with :func:`wrap_svg_zoomable`).


## `wrap_svg_zoomable`

```python
wrap_svg_zoomable(svg: str, width: float | None = None, height: float = 700) -> str
```

Wrap an SVG in a zoomable, scrollable container.

The container has the given pixel dimensions.  When *width* is ``None``
the container fills the available width.  Users can pan by scrolling
and zoom with pinch-zoom (trackpad) or Ctrl/Cmd + wheel.  Zoom is
anchored at the cursor position.

**Parameters:**

- `svg` (`str`) — Raw SVG markup.
- `width` (`float | None`) — Pixel width of the container, or ``None`` for full width.
- `height` (`float`) — Pixel height of the container.
