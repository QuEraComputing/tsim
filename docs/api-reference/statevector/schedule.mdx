---
title: "schedule"
description: "Reordering of Pauli operations to keep the dense array small."
---

Two operations must keep their relative order exactly when they anticommute;
every order that respects these pairs gives the same distribution. The active
width k = n − dim S, as in Clifft (arXiv:2604.27058), is tracked with the Pauli
group S that stabilizes every trajectory up to sign. ``schedule`` runs
measurements as early as possible and widening rotations as late as possible:
when nothing else can run, it runs the pending measurement whose unrun
ancestors reach the smallest width, the earliest one on a tie.

## class `PauliOps`

```python
PauliOps(kind: np.ndarray, x: np.ndarray, z: np.ndarray, angle: np.ndarray, sign: np.ndarray, slot: np.ndarray)
```

Rotations and measurements in the frame of the initial ``|0…0⟩`` state.

Op ``j`` is the rotation ``exp(-iθ (-1)^s P)`` or the measurement of
``(-1)^s P``, where ``P`` has the bit rows ``x[j]`` and ``z[j]`` (``Y``
where both are set) and ``s`` is the parity of ``sign[j]`` against
``[1, f_0, f_1, …]``. A measurement records its eigenvalue bit.


### `take`

```python
take(order: np.ndarray) -> PauliOps
```

Return the operations in the given order.

The result describes the same distribution when ``order`` keeps every
pair of anticommuting operations in their original order.


## class `Schedule`

```python
Schedule(order: np.ndarray, width: int)
```

An order of the operations and the largest active width it reaches.


## class `StabilizerGroup`

```python
StabilizerGroup(num_qubits: int)
```

Generators, up to sign, of the Pauli group stabilizing every trajectory.


### `anticommuting`

```python
anticommuting(x: np.ndarray, z: np.ndarray) -> np.ndarray
```

Return which generators anticommute with the Pauli ``(x, z)``.


### `contains`

```python
contains(x: np.ndarray, z: np.ndarray) -> bool
```

Return whether ``(x, z)`` is a product of the generators, up to sign.

The generators commute and are independent, so their rank is their number.


### `copy`

```python
copy() -> StabilizerGroup
```

Return an independent copy of the group.


### `measure`

```python
measure(x: np.ndarray, z: np.ndarray) -> None
```

Update the generators after measuring the Pauli ``(x, z)``.


### `rotate`

```python
rotate(x: np.ndarray, z: np.ndarray) -> None
```

Keep the generators that a rotation about ``(x, z)`` preserves.


## `anticommutation`

```python
anticommutation(ops: PauliOps) -> np.ndarray
```

Return the symmetric matrix of which pairs of operations anticommute.


## `anticommute`

```python
anticommute(x1: np.ndarray, z1: np.ndarray, x2: np.ndarray, z2: np.ndarray) -> np.ndarray
```

Return which Paulis ``(x1, z1)`` anticommute with which Paulis ``(x2, z2)``.

Each row of an argument is a Pauli; a 1-D argument is one Pauli, whose axis
the result drops.


## `schedule`

```python
schedule(ops: PauliOps) -> Schedule
```

Return an order of ``ops`` that keeps the active width small.
