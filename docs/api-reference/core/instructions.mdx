---
title: "instructions"
description: "ZX graph representations of quantum gates and instructions."
---

Each gate is a function that builds onto a ``GraphBuilder`` through its methods
(``tsim.core.builder``); ``GATE_TABLE`` maps Stim gate names to them.

Gates are built up to a global phase: every graph is a doubled diagram (a
channel, ``U ⊗ Ū`` for a unitary), where global phases cancel, so none are
tracked.

## class `GraphBuilder`

```python
GraphBuilder()
```

Builds the ZX graph of a stim circuit, with quantum wires and classical records.

Qubit wires are quantum; measurement records, detectors and observables are
classical spiders, read through the properties below (their labels are only
for display). ``build`` returns the finished open or closed graph.


### `add_channel`

```python
add_channel(probs: np.ndarray) -> int
```

Record a noise channel and allocate its error bits.

``probs`` is the channel's distribution over its ``k`` error bits, so it
has ``2^k`` entries. Returns the first bit; the channel owns bits
``first … first + k − 1``. Raises ``ValueError`` if the number of
entries is not a power of two.


### `add_detector`

```python
add_detector(record_indices: list[int]) -> None
```

Add a detector that XORs the given measurement records.


### `advance`

```python
advance(qubit: int) -> None
```

Move the wire's end one column (the identity gate).


### `build`

```python
build(closed: bool, outputs: Outputs) -> Graph
```

Return the circuit's graph with its wires closed or given ports.

With ``closed=False``, qubit ``q``'s wire start, if it is still a
boundary, gets input port ``-(q + 1)`` and its end gets output port
``q``. With ``closed=True``, wire starts that are still boundaries become
``|0⟩`` (a quantum X(0) spider) and wire ends are discarded. Helper lanes
(negative indices, used by MPP, MPAD and heralded channels) are always
discarded at the end.

``outputs`` picks the classical output boundaries, whose ports follow the
qubit outputs (from 0 when closed):

- ``"detectors"``: one per detector, then one per observable; the
  ``det[i]`` / ``obs[k]`` labels move to them.
- ``"records"``: one per measurement record; the ``rec[i]`` labels move
  to them.
- ``"none"``: no classical outputs.

Detector and observable spiders are removed unless they are the outputs.
In open graphs, measurement spiders that are not outputs keep their
``rec[i]`` / ``m[i]`` labels; closed graphs are meant to be reduced, so
only their output boundaries carry labels, which survive reduction.

An open graph's tensor is the circuit's channel together with the output
bits; for bound error parameters, a closed graph's tensor is the joint
distribution of its outputs. The builder is unchanged, so it can build
again.


### `correlated_error`

```python
correlated_error(qubits: list[int], types: list[Literal['X', 'Y', 'Z']], p: float) -> None
```

Add a correlated error term affecting multiple qubits with given Pauli types.

The term is the next link of the pending chain. It flips one noise spider
per Pauli component (X or Z on a qubit), reusing the chain's spider of
that component while nothing else has acted on the wire since (see
``_chain_spider``). The spiders get their error bits in
``finalize_correlated_error``, which must run before the graph is built.
Raises ``ValueError``, and changes nothing, if ``qubits`` and ``types``
differ in length.

### `finalize_correlated_error`

```python
finalize_correlated_error() -> None
```

Finalize the current correlated error channel.

A chain of ``k`` links on ``c`` live noise spiders (those that some link
flips) becomes a channel over ``min(c, k)`` error bits: one bit per
spider if ``c \< k``, so that link ``j`` sets the bits of the spiders it
flips, and one bit per link otherwise, so that a spider's phase is the
parity of the links that flip it. Clears the pending chain, also when it
raises ``ValueError`` because the channel would have more than
``MAX_CORRELATED_ERROR_BITS`` bits.

### `measure`

```python
measure(qubit: int, silent: bool = False) -> Vertex
```

Measure a qubit in the Z basis and record it as ``rec[i]``.

A silent measurement is not recorded; it is labelled ``m[i]``. Returns
the measurement's classical spider.


### `reset`

```python
reset(qubit: int) -> None
```

Reset a qubit to ``|0⟩``.

If the qubit does not yet have a lane, create one in the reset state.
Otherwise, silently measure the existing lane to trace out the previous
state before reconnecting the qubit in the reset state.


### `spider`

```python
spider(qubit: int, vertex_type: VertexType, phase: Phase | Fraction | None = None, col: float | None = None) -> Vertex
```

Turn the trailing boundary of a qubit's wire into a quantum spider.

The spider keeps the boundary's quantum domain, moves to column ``col``
if given, and a new quantum boundary is appended after it. Returns the
spider.

## `heralded_pauli_channel_1`

```python
heralded_pauli_channel_1(builder: GraphBuilder, qubit: int, pi: float, px: float, py: float, pz: float) -> None
```

Apply heralded single-qubit Pauli channel.

Records a herald bit into the measurement record. When the channel fires
(with total probability pi+px+py+pz), the herald is 1 and one of I/X/Y/Z
is applied. When it doesn't fire, the herald is 0 and nothing happens.


## `heralded_pauli_channel_1_probs`

```python
heralded_pauli_channel_1_probs(pi: float, px: float, py: float, pz: float) -> np.ndarray
```

Heralded single-qubit Pauli channel. Returns shape (8,).

Bit layout:
- bit 0: herald bit, written to the measurement record
- bit 1: Z error component
- bit 2: X error component

The non-zero outcomes are:
- index 0 (0b000): no herald, no Pauli error
- index 1 (0b001): herald + I
- index 3 (0b011): herald + Z
- index 5 (0b101): herald + X
- index 7 (0b111): herald + Y, represented as X+Z

## `pauli_channel_2_probs`

```python
pauli_channel_2_probs(pix: float, piy: float, piz: float, pxi: float, pxx: float, pxy: float, pxz: float, pyi: float, pyx: float, pyy: float, pyz: float, pzi: float, pzx: float, pzy: float, pzz: float) -> np.ndarray
```

Two-qubit Pauli channel. Returns shape (16,).

Bit layout:
- bit 0: Z error component on ``qubit_i``
- bit 1: X error component on ``qubit_i``
- bit 2: Z error component on ``qubit_j``
- bit 3: X error component on ``qubit_j``

With that layout, index ``z_i + 2*x_i + 4*z_j + 8*x_j`` stores the
probability for the corresponding two-qubit Pauli outcome. The arguments
follow Stim's naming convention: ``pix`` is I on ``qubit_i`` and X on
``qubit_j``, ``pzi`` is Z on ``qubit_i`` and I on ``qubit_j``, etc.

## `r_pauli`

```python
r_pauli(builder: GraphBuilder, paulis: list[tuple[Literal['X', 'Y', 'Z'], int]], theta: Fraction, dagger: bool = False) -> None
```

Apply exp(-i theta pi/2 P) for a Pauli product P, with theta in half-turns.

Generalizes ``SPP`` (theta=1/2) and ``TPP`` (theta=1/4) to an arbitrary angle.
For a single qubit, ``r_pauli`` reduces to the named single-qubit rotation in
that Pauli's basis (e.g. ``R_PAULI Z0`` is ``R_Z``). If `dagger` is True, apply
exp(+i theta pi/2 P) instead.

**Parameters:**

- `builder` (`GraphBuilder`) — The graph builder to modify.
- `paulis` (`list[tuple[Literal['X', 'Y', 'Z'], int]]`) — List of (pauli_type, qubit) pairs defining the Pauli product P.
- `theta` (`Fraction`) — Rotation angle in half-turns (units of pi).
- `dagger` (`bool`) — If True, negate the rotation angle.
